# StockPulse AI

Real-Time Indian Stock Analytics Platform built using React, FastAPI and yFinance.

## Features

### Market Analytics
- Live NSE Stock Prices
- Market Overview Dashboard
- Auto Refresh
- Market Status

### Technical Analysis
- RSI Indicator
- SMA20
- SMA50
- Trend Detection

### Trading Signals
- Buy Signal
- Sell Signal
- Hold Signal
- Confidence Score
- Signal Reasoning

### User Experience
- Stock Search
- Quick Stock Selection
- Responsive Dashboard
- Modern Fintech UI

## Tech Stack

### Frontend
- React
- Vite
- TailwindCSS
- Axios

### Backend
- FastAPI
- Python
- yFinance
- TA Library
