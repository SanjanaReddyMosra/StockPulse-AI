# StockPulse AI

Real-time Indian stock analytics platform with AI-powered trading insights, technical indicators, and live NSE/BSE stock tracking.

## Features
- Live Indian stock prices
- FastAPI backend
- React + Tailwind dashboard
- AI Buy/Sell/Hold signals
- Technical indicators
- Real-time analytics

## Tech Stack
- React
- TailwindCSS
- FastAPI
- yFinance
- MongoDB (upcoming)

## Setup
Frontend:
npm install
npm run dev

Backend:
uvicorn main:app --reload
